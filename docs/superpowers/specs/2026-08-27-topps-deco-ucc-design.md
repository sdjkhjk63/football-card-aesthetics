# Topps Deco UEFA Club Competitions 2025-26 Design

**Approved:** 2026-08-27

## Goal

Add the 2025-26 Topps Deco UEFA Club Competitions product to Card Aesthetics and deploy the updated Windows desktop application.

## Catalogue scope

- Publish 22 independently rateable visual card families backed by reviewed local images: nine main-set faces, Razzmatazz, Cubist, ten autograph layouts, and Antiquity Autograph Relic.
- Do not publish Only1 until a trustworthy representative image is available.
- Use the official product image as the series packaging entry point.
- Provide Chinese, English, and Spanish series names, card names, and image alternative text.
- Record the standard numbered ladder as Blue /99, Green /75, Purple /50, Orange /25, Black /10, Red /5, and Gold 1/1 where applicable.
- Mark horizontal multi-subject autograph cards as landscape.
- Keep all displayed images local and mark them exact only after successful image validation.

## Product facts

- Product configuration: 10 packs per box, 8 cards per pack.
- Box guarantee: 1 autograph and 3 numbered parallels.
- Main checklist size: 192 cards.

## Delivery

- Add the series and every card route to the static desktop build.
- Add catalogue and route regression tests.
- Build the Electron application and Windows installer.
- Install the updated application under the existing Card Aesthetics user installation.
- Verify that the installed `app.asar` hash matches the freshly built artifact.
